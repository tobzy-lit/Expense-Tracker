# Expense Tracker

A command-line expense tracker built with Python. This project helps users record and manage their daily expenses.

## Features

- Add expenses with an amount, category, and description.
- View recorded expenses.
- Calculate total expenses.
- Search expenses by category.
- Delete expenses.
- Save expenses to a JSON file.
- Load saved expenses when the program starts.
- Validate user input.

## Technologies

- Python 3
- JSON

## How to Run

1. Clone this repository.
2. Open the project directory in your terminal.
3. Run the application:

   ```bash
   python3 main.py
